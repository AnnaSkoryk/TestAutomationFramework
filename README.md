# 🔍 Web Test Automation Framework for UI & API

A robust and extensible test automation framework designed for comprehensive testing of both **UI** and **API** layers. Currently tailored for the live test environment at [automationexercise.com](https://automationexercise.com/), this framework provides a strong foundation for scalable and maintainable automated test suites.

---

## 🚀 Key Features

- ✅ Automated UI testing using **Selenium WebDriver**
- 🔄 RESTful API validation with full control of HTTP requests & responses
- ⚙️ Integration-ready architecture for CI/CD pipelines
- 🧪 Built with **nUnit** for structured and reusable test scenarios
- 💻 Developed in **.NET 9** using **Visual Studio 2022**
- 🌐 Cross-layer testing (Frontend and Backend)
- 📈 Easy to scale: Add more tests or extend to other projects with minimal configuration

## 💡 Motivation

Modern applications demand reliability and performance across both user interface and backend services. This framework was created to ensure web resources like `automationexercise.com` can be validated at every layer — visually and logically.

The design reflects best practices in automation architecture, scalability, and clean code, making it suitable for real-world QA processes and collaborative development teams.

## 🧰 How to Build Locally

1. **Clone the Repository**
  ```bash
  git clone https://github.com/your-username/your-repo-name.git
  cd your-repo-name
  ```
2. **Open the Solution**
  Open the .sln file in Visual Studio 2022
3. Restore Dependencies
  Build the solution or use:
  ```bash
  dotnet restore
  ```
4. Run Tests
- Directly from Test Explorer in Visual Studio
- Or via command line:
  ```bash
  dotnet test
  ```
